Para empezar a crear las pantallas debeis usar el archivo llamado plantilla_base. 
En el encontraréis una plantilla donde deberéis pegar vuestro html y crear su propio javaScript para cargar los datos desde su PHP,
Tenéis conectar vuestro visual estudio con github, preguntadle a gemini como se hace <3 y como siempre primero un pull antes de trabajar
y si se va a hacer algun commit o modificación debéis avisarlo.
